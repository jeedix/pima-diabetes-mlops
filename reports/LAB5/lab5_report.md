## 1. Схема настроек (pydantic)

Конфиг `Lab5Config` (`src/generator_config.py`) состоит из трёх частей:

- **`GeneratorDataConfig`** — путь к реальным данным (`real_parquet`), путь выхода (`output_parquet`), целевая колонка (`target`), количество образцов (`n_samples`), зерно (`seed`). Валидатор проверяет существование входного файла, `n_samples ∈ [100, 100000]`.
- **`GeneratorOutputConfig`** — режим (`similar` / `random`), ручки дрейфа (`DriftConfig`).
- **`DriftConfig`** — `shift_mean` (сдвиг средних, −10…10), `flip_labels` (переворот меток, 0…1), `scale_features` (масштабирование, 0…10).

`mlflow_experiment` — имя эксперимента MLflow.

## 2. Семейство генератора (P1: табличный)

**Режим «similar»** — бутстрэп: случайная выборка с возвращением из реальных данных. Статистически идентичен реальным данным, воспроизводим при фиксированном seed.

**Режим «random»** — равномерный шум в диапазонах реальных признаков (min…max для каждого признака). Не связан со структурой реальных данных.

**Ручки дрейфа:**
- `shift_mean` — добавление константы к каждому числовому признаку.
- `scale_features` — умножение на коэффициент.
- `flip_labels` — случайный переворот бинарных меток с заданной вероятностью.
